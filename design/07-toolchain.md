# 7. 工具链

## 热重载（杀手级体验）

模板改动 → 只重编译该模板的 RenderUnit → 保留 code-behind 的 signals 实例、
按 Key 对齐新旧元素子树。**"改 UI 不丢状态"**。

依赖的基础设施（模板独立编译单元 + Key 对齐）已在主设计中具备，
IDE 侧只需接上更新协议。

## 调试器映射

- 生成的 C# 带 `#line` 指令指向 `.bui` 源位置，断点可直接下在模板的 `{}` 表达式上，
  步进时调用栈显示模板行号。
- 与热重载同属 span 映射表机制族——**生成器设计期即把映射表当一等输出**，
  事半功倍。

## 无头测试（测试一等公民）

- 不开窗口实例化模板，断言元素树、布局结果、触发事件。
- 光栅化断言（截图对比）用 `vello_cpu`（多线程 + SIMD 的纯 CPU 路径，
  不依赖 GPU），跨硬件的像素差异用容差比较。
- CI 可直接跑；补上 Blazonia issue #4（无单元测试）这类欠账的架构级答案。

## DevTools

- 元素树检查器（实时改属性）。
- 失效链可视化：组件 `Invalidate` → `Render` → 块 `Refresh` 的调用归属与耗时（无依赖图/订阅关系）。
- 帧剖析：layout / paint / damage 各自耗时、draw call 统计。
