# 焦点状态与提示验证 · 2026-11-14

当前契约见 [design/25](../25-focus-visuals.md)。F1–F4 已实施，真实焦点状态、样式、控件自身提示、绘制和脏区使用同一条管线。

## 行为与接口

- 新增 IsFocusWithin / IsFocusVisible，只读且不能通过模板赋值或 @bind；原 IsFocused / :focus 保持直接焦点含义。
- 每个根独立记录 Pointer / Keyboard 方式，程序请求继承当前方式；同一目标切换方式只更新提示，不重复发送焦点事件。
- PointerPress 前置通知；有效 KeyPress 在 Escape / Preview 处理前通知；鼠标移动、滚轮和字符输入不更改方式。
- 文本编辑器使用一层自身边框；ComboBox / DatePicker 由外壳根据 focus-within 提示。列表、树、表格与页签使用当前行或头部几何。
- Popup 弱引用保存原目标，Escape 与外部点击按关闭时的方式恢复；无效、摘除或跨根目标不恢复。
- Element.FocusVisualMode 支持 Auto / Outline / Control / None；FocusRingWidth / Offset / Color 可通过样式设置，Color 支持 theme()。Window / WindowHostOptions / FocusManager 支持 AlwaysShowFocusVisuals。
- 自定义控件可覆盖 FocusVisualTarget / GetFocusVisualGeometry / RenderFocusVisual，无需扩展绘制器类型分支。

## 绘制与生命周期

Outline 描述符统一提供命令、段缓存键和 damage 所需的目标、范围、颜色、宽度、偏移和裁剪。自身命令在子内容前输出，焦点装饰在子内容及自身裁剪结束后输出；导航目标与所有者之间的滚动视口裁剪被保留。

提示隐藏时覆盖旧区域；宽度、正负偏移、圆角和模式变化均与 CPU 整帧渲染逐像素比较，retained 合成哈希一致。抗锯齿边缘按缩放保留余量。静止帧复用全部段、damage 为空。像素 golden 基线未改动。

状态先统一提交，再发布样式与 LostFocus / GotFocus；公共祖先不重复切换 focus-within。无效目标、父级禁用/隐藏、摘除/释放、原根重新挂入另一根均清理状态；重入请求排队，100 轮上限防止循环。替换 FocusManager 时先移交根所有权，使旧管理器在焦点回调中不能重新接收请求；Ctrl+Tab 从页内编辑器切页后把焦点移至当前页签头，避免旧页隐藏后失去导航位置。焦点回调抛异常时仍完成队列和结构清理。

验证中发现 PathGeometry.Bounds 把 Close 的默认零坐标纳入包围盒，导致正坐标路径的范围错误；现跳过没有坐标负载的 Close，未改变路径或像素输出。
