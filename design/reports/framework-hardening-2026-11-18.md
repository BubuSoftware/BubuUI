# 框架修复与本机验收（2026-11-18）

范围：本轮框架盘点发现的控件行为、Fluent 属性覆盖、文本编辑、大数据列表、GPU 重绘和 macOS 应用包问题。按用户要求完成本机可验证部分，设备与正式分发相关的验收单列，不以模拟测试代替真机结果。

## 已修复

| 问题 | 修复与回归覆盖 |
|---|---|
| DataGrid 变高行按固定行高滚动，End 选中末项却不可见 | 用虚拟面板的测量/估计条目区域定位；新行高测量后继续校正，用户后续滚动优先；保留无限宽探测前的实际宽度与主题 |
| TreeView 清空 ItemsSource 后保留旧节点 | 跟踪并释放生成节点，清理失效选择；保留后来手工添加的节点 |
| ListBoxItem、Popup 等 Fluent 外观忽略公开属性 | 默认背景、状态和圆角通过主题资源及样式提供；绘制读取控件的有效属性，局部 Background/BorderBrush/CornerRadius 覆盖生效；投影内容的指针按下状态传给所属列表/树项 |
| 编辑 ZWJ、组合符和旗帜后光标落入字素中间 | 编辑和撤销恢复后重新对齐完整字素边界，保留选区方向；后续输入及删除不拆坏组合字符 |
| 大 ListBox/ComboBox 全量创建容器，刷新时重复扫描 | 128 项起自动虚拟化，有限滚动视口只创建可见行及缓冲；选择按数据索引，支持 Home/End、初始选中项及指针操作；集合匹配采用索引队列，保留匹配容器和编辑状态；全选后的集合刷新也使用索引匹配 |
| GPU 小范围变化仍完整构建并光栅化 | 缓存原生场景片段；保留共享裁剪、透明度与混合图层；脏区只在小纹理中光栅化，再覆盖持久帧纹理；尺寸变化和异常后重建完整帧 |
| macOS 只有开发目录中的可执行程序 | 新增标准 .app、原生启动器、递归依赖捆绑与重定位、架构校验、内部到外部签名、严格验证及 CI 归档 |

列表自动虚拟化可用 `IsVirtualizationEnabled=false` 关闭。达到阈值后缩小数据源仍保持虚拟模式，直到清空或禁用；调用方提供 Element 和手工 Children 保留普通布局；无滚动祖先时全量布局。运行时控件仍不依赖 Fluent，外观变化在独立主题项目中完成。

GPU 目前将多块脏区合并为一个向外对齐的设备像素包围矩形。最终上屏仍是全屏纹理复制，没有 CPU 回读；未宣称消除全部全屏带宽。变换与图层作用域交叉的合法显示列表回退完整场景构建，保持原语义。

### 已知验证限制

`PixelGoldenTests.PixelGoldens_MatchBaseline` 仍有既有跨平台精确哈希差异：本机 `solid-primitives` 为 `545973A7E136D408`（基线 `FA65021E5F9A5DAD`），`transform-clip` 为 `320080985B30C305`（基线 `0AD8AFE436161042`）。语义探针通过；这些场景直接经未改动的 Vello CPU 绘制路径运行。本轮前的独立源码验证已复现相同失败；历史跨平台差异也见[Linux 报告](./linux-platform-2026-11-14.md#精确像素基线差异)。此项未解决，不将渲染全套报告为全绿。

Release 裁剪发布仍报告 3 条既有 IL2075 警告，来自 DataGridColumn 的动态属性路径反射。任意用户数据类型在裁剪后是否保留属性元数据不能由此次发布保证；裁剪应用应使用显式 ValueGetter/ValueSetter，或在应用中保留所需反射成员。此次未通过隐藏警告或关闭裁剪来改变结果。

第二显示器跨屏缩放、Intel Mac、真实输入法候选窗口及死键、干净机器启动、Developer ID 签名及公证/Gatekeeper 分发仍需对应环境。此次只使用本地 ad hoc 签名，没有上传公证；Windows/Linux 原生窗口不能由本机 Mac 验收。远端 CI 已配置，但本报告不把配置等同于远端运行成功。
