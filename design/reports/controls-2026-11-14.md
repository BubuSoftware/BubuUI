## Win32 与 GPU 验证

```powershell
dotnet run --project sandbox/ControlNativeCheck --no-restore
```

结果：native input selfcheck passed，12 帧，Vello GPU surface。

- WM_CHAR 依次输入 A、你和 emoji 代理对，编辑器内容为 A你😀。
- End/Backspace 经原生消息桥接删除整个 emoji，内容为 A你。
- KeyUp 到达运行时；Escape 的 KeyUp 也在恢复焦点后到达。
- Escape 关闭下拉框并恢复焦点，窗口继续运行至最后断言，再由验证壳关闭。
- 验证壳检查完成标志，窗口提前退出会导致自检失败。

该自动化验证不替代实际中英文输入法的候选窗口人工验收；IMM32 开始/更新/提交/取消已接入，组合更新与提交语义另有无头回归。
